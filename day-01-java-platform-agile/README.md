# Day 1: Java Platform Basics + Agile/Scrum Basics

## 🎯 Learning Objectives
By the end of this day, you will understand how Java works under the hood and grasp the core concepts of the Agile/Scrum methodology.

**⏱️ Estimated Study Time:** 3-4 hours

## 📚 Topics to Learn
1. **Java Platform Architecture:**
   * JDK (Java Development Kit) vs JRE (Java Runtime Environment) vs JVM (Java Virtual Machine).
   * Java compilation flow: `.java` (Source) → `javac` (Compiler) → `.class` (Bytecode) → JVM (Execution).
   * **JVM Architecture:** Class loader, runtime data areas, execution engine, interpreter, JIT (Just-In-Time) compiler, and garbage collection.
2. **Agile & Scrum:**
   * Agile mindset and Scrum framework.
   * Ceremonies: Sprints, Daily Standups, Retrospectives.
   * Artifacts: User Stories, Story Points estimation, and Definition of Done (DoD).

## 🛠️ Practical Tasks

### Task 1: Java Environment & Execution
1. Install and verify JDK 21 on your machine.
2. Review the code in `src/PlatformInfo.java` which prints out your Java version, OS, processor count, and heap memory.
3. **Compile and execute** using the terminal (no IDE):
   ```bash
   cd src
   javac PlatformInfo.java
   java PlatformInfo
   ```
4. **Inspect bytecode:** Run `javap -c PlatformInfo` to see the generated bytecode instructions.
5. **Explore class loading:** Run `java -verbose:class PlatformInfo` to watch the JVM load required classes.

### Task 2: Agile User Stories
Write 8 User Stories for a sample software project (e.g., an Online Bookstore) in `deliverables/user-stories.md`. Include Story Points (e.g., Fibonacci scale: 1, 2, 3, 5, 8) and a Definition of Done.

## 📝 Practice Questions
1. Why is Java called "Write Once, Run Anywhere" (WORA)?
   * *Answer:* Java compiles to platform-independent bytecode. The JVM on each specific operating system translates this bytecode into machine code.
2. What is the role of the JIT compiler?
   * *Answer:* It improves performance by compiling frequently executed bytecode into native machine code at runtime.

## 🐛 Common Errors & Troubleshooting
* **`javac is not recognized`**: The JDK `bin` folder is not in your system's `PATH` environment variable. Add it!
* **`Error: Could not find or load main class`**: Ensure you are in the correct directory (`src/`) and typing `java PlatformInfo` without the `.java` or `.class` extension.
