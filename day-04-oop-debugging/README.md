# Day 4: OOP Concepts & Debugging

## Overview
Focusing on Object-Oriented Programming (OOP) and how to debug applications.

## Topics
- Classes, objects, methods, constructors.
- Encapsulation, access modifiers.
- Static vs instance members.
- Debugging in an IDE (breakpoints, step over, step into).

## Exercises
1. Implement a BankAccount class in `src/com/hcl/bank/BankAccount.java`.
2. Use encapsulation for balance, and implement deposit/withdraw methods.
3. Add a bug intentionally and practice using the IDE debugger to find it.
