Each daily folder contains a `README.md` with instructions, a `notes/` folder, a `src/` folder for Java code, and a `deliverables/` folder for screenshots and outputs.

## Daily Checklist & Update Instructions
As I complete each day:
1. Review the day's README and study the materials in the `notes/` folder.
2. Complete the coding tasks in the `src/` folder.
3. Save screenshots and outputs to the `deliverables/` folder.
4. Check off the items in the daily README checklist.
5. Update this root README table to change status to `🟢 Completed`.
6. Commit and push the progress to GitHub.
