# Day 2: Language Fundamentals & Git

## Overview
This covers basic Java programming and Git commands.

## Topics
- Variables and constants.
- Primitive data types and their ranges.
- Operators and type casting.
- 1D and 2D arrays.
- Git basics: working directory, staging area, local repository.
- Basic commands: status, add, commit, push, pull.

## Exercises
1. Build `src/MonthlyUsageAnalyser.java`.
2. Use arrays, constants, and operators to calculate usage statistics.
3. Test out integer overflow.
4. Compile and run:
   ```bash
   cd src
   javac MonthlyUsageAnalyser.java
   java MonthlyUsageAnalyser
   ```
5. Commit and push changes.
