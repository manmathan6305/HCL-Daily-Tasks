# Day 5: Inheritance, Polymorphism & Git Branching

## Overview
Covering advanced OOP concepts like inheritance and polymorphism, along with Git branching and merging.

## Topics
- Inheritance (extends, super).
- Abstract classes and interfaces.
- Method overriding and overloading.
- Git branches and merge conflict resolution.

## Exercises
1. Implement a payment processing system in `src/com/hcl/payment/PaymentDemo.java`.
2. Use abstract classes and interfaces to represent different payment methods.
3. Create a new git branch, make a change, and merge it back to main.
